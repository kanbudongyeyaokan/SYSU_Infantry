# 底盘 S 曲线（动态跟踪器）调参指南
在使用二阶阻尼 S 曲线算法时，底盘就像被一根**带阻尼的隐形弹簧**牵引。调参的核心在于寻找**起步爆发力**、**刹车抱死感**与**裁判系统功率红线**之间的完美平衡。

## 1. 核心参数速查表
| 参数名 | 物理意义 | 调参口诀 | 典型取值范围 |
| ---- | ---- | ---- | ---- |
| kp_acc | 加速弹簧刚度 | 决定起步的“推背感”。值越大，加速越猛、跟手感越强。 | 100.0 ~ 400.0 |
| kp_brk | 刹车弹簧刚度 | 决定松开摇杆时的“抱死”速度。通常设为 kp_acc 的 1.5 到 2 倍。 | 200.0 ~ 800.0 |
| kd | 运动阻尼系数 | 消除车身震荡的“减震器”。必须配合 Kp 调整，公式为 $K_d \approx 2\sqrt{K_p}$。 | 20.0 ~ 55.0 |
| max_a | 物理加速度极限 | 防翻车、防超功率的“叹息之墙”。它是硬性截断，不影响跟手节奏。 | 6000.0 ~ 15000.0 |

## 2. 标准调参四步法
### Step 1：解开封印 (拉高 max_a)
为了看清 kp 的真实效果，先将 max_a 放大到 15000 左右，避免加速度被过早削平。
**注意**：此阶段严禁操作手猛推满摇杆，防止电容瞬间抽干。

### Step 2：寻找暴躁起步 (调 kp_acc & kd)
缓慢推摇杆，如果觉得起步肉，就把 kp_acc 往上加（每次加 50）。
加完之后，套用公式 $K_d \approx 2\sqrt{K_p}$ 算出新的 kd。
- 如果车子停下时来回抽搐（欠阻尼），就把 kd 再加 5；
- 如果车子像陷入泥潭一样迟钝（过阻尼），就把 kd 减小。

### Step 3：打造指哪打哪的刹车 (调 kp_brk)
起步舒服后，测试急松摇杆。如果车子往前滑行太远，就猛加 kp_brk（直接加 100）。
此时阻尼 kd 保持不变即可。

### Step 4：压制极限收场 (下压 max_a)
让操作手进行**“死亡折返跑”**和**“满速急刹”**。
观察裁判系统：如果出现功率超限扣血，或者底盘有翘头侧翻的趋势，**不要动 Kp**，而是把 max_a 逐渐往下压（比如压到 9000），直到刚好不超功率为止。
